# Contributing to JobsDirect-MCP

First off, thank you for considering contributing to **JobsDirect-MCP**! Your help is essential for keeping this tool the premier open-source choice for agentic job search, intelligent ATS fit evaluation, and career application automation.

We welcome contributions of all kinds from developers, prompt engineers, career coaches, and job seekers.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub issue search — check if the issue has already been reported.
- Check if the issue has been fixed — try to reproduce it using the latest `main` branch.
- Open an Issue and provide a clear, descriptive title.
- Include steps to reproduce the issue, the prompt or portal queried, and what error or behavior occurred.

### Suggesting Enhancements & New Portals
- Open an Issue describing the target job board or ATS enhancement.
- Explain how adding this portal or feature benefits job seekers worldwide.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure your code follows clean asynchronous Python practices and adheres to FastMCP standards.
3. Keep the 4-tier ATS algorithm dynamic and candidate-agnostic (avoid hardcoding individual candidate profiles or static blacklists).
4. Issue that pull request!

## Code of Conduct
This project and everyone participating in it is governed by the [JobsDirect-MCP Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
