# Security Policy

## Supported Versions

JobsDirect-MCP is an open-source tool for agentic job search and application preparation. We actively maintain and provide security updates for the latest releases:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security and user privacy are foundational principles of JobsDirect-MCP, especially because this tool processes personal resumes, contact details, and career histories locally on the user's machine.

If you discover a security vulnerability or privacy leak within JobsDirect-MCP, please do not disclose it publicly.

Instead, please open a private security advisory on GitHub or contact the repository maintainer. We endeavor to respond to all security reports promptly and release patches as quickly as possible.
